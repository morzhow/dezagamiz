# dezagamiz — Платформа оплаты заправки (АГНКС и АЗС) прямо из салона авто

Полноценное веб-приложение на **React + TypeScript + Express + Tailwind CSS v4** с картой станций Узбекистана, живым трекером колонки, картами Uzcard/Humo/dezagamiz, 5 языками (`RU`, `UZ`, `EN`, `KK`, `TR`), персональной музыкальной студией, ИИ-помощником Gemini и встроенным **режимом презентации и защиты для школьного конкурса**.

---

## Как открыть и запустить проект в Visual Studio Code (VS Code)

### Шаг 1. Установка программ на компьютер
1. Скачайте и установите **Node.js (LTS, версия 20 или новее)**: https://nodejs.org
2. Скачайте и установите **Visual Studio Code**: https://code.visualstudio.com

### Шаг 2. Перенос проекта в VS Code
1. Скачайте архив проекта (или склонируйте папку) на ваш компьютер и распакуйте его, например, в `Documents/dezagamiz`.
2. Откройте VS Code → **File → Open Folder...** → выберите папку `dezagamiz`.
3. VS Code сам предложит установить рекомендуемые расширения (Tailwind CSS и TypeScript) — нажмите **Install**.

### Шаг 3. Настройка переменных окружения (`.env`)
1. В корне проекта скопируйте файл `.env.example` и переименуйте копию в `.env`.
2. При необходимости укажите ваши ключи (опционально — без ключей приложение всё равно запускается с резервной картой и мелодиями):
   ```env
   GEMINI_API_KEY="ваш_ключ_gemini"
   VITE_GOOGLE_MAPS_API_KEY="ваш_ключ_google_maps"
   GOOGLE_MAPS_API_KEY="ваш_ключ_google_maps"
   ```

### Шаг 4. Установка пакетов и запуск
Откройте встроенный терминал в VS Code (`Ctrl + ~` или **Terminal → New Terminal**) и выполните по очереди:

```bash
npm install
npm run dev
```

После запуска откройте браузер и перейдите по адресу:
👉 **http://localhost:3000**

> Совет: В VS Code также настроена кнопка **F5** («Run and Debug → dezagamiz: Start Dev Server»).

## Полезные команды

| Команда | Что делает |
| :--- | :--- |
| `npm run dev` | Запуск сервера и интерфейса в режиме разработки на порту `3000` |
| `npm test` | Запуск всех автоматических модульных тестов |
| `npm run lint` | Проверка типов TypeScript (`tsc --noEmit`) |
| `npm run build` | Сборка готового проекта в папку `dist/` |
| `npm start` | Запуск продакшн-сборки |
